# 光场 · Effects Lab

一个零依赖的浏览器粒子特效小工具。使用原生 HTML、CSS、JavaScript 与 Canvas 2D。

## 运行

下载 `index.html`，用现代浏览器直接打开即可，无需安装依赖、构建或登录。

## 功能

- 粒子星河、流光波浪、轨道光环三种实时特效
- 自定义颜色，调节粒子数量、速度与辉光
- 指针吸引粒子，点击释放涟漪
- 暂停 / 继续、恢复默认参数
- 导出当前画布为 PNG（不包含控制面板）
- 自适应手机与桌面布局，尊重系统减少动态效果偏好

所有计算均在浏览器本地完成，不发送数据，不使用外部资源。

## 文件

`index.html` 包含完整页面、样式及程序，可以独立复制和运行。

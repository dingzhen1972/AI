# 光场 v2 · Effects Lab

一个零依赖的浏览器粒子特效小工具。使用原生 HTML、CSS、JavaScript 与 Canvas 2D。

## 运行

下载 `index.html`，用现代浏览器直接打开即可，无需安装依赖、构建或登录。

## 功能

- 三套一键预设：紫色星梦、极光海洋、日落轨道
- 随机灵感：一键组合效果、配色和动态参数
- 保存 / 恢复参数：保存在当前浏览器，保存会覆盖上次记录，重置不会删除保存记录
- 粒子星河、流光波浪、轨道光环三种实时特效
- 自定义颜色，调节粒子数量、速度与辉光
- 指针吸引粒子，点击释放涟漪
- 暂停 / 继续、恢复默认参数
- 导出当前画布为 PNG（不包含控制面板）
- 自适应手机与桌面布局，尊重系统减少动态效果偏好

所有计算均在浏览器本地完成，不发送数据，不使用外部资源。

保存参数使用 localStorage。浏览器禁用存储时会显示提示；不同浏览器或不同地址不会共享参数，直接打开本地文件时存储行为可能因浏览器而异。保存的是参数，不是画面中的随机粒子位置。读取无效数据时保留当前效果。
